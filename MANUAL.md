# Руководство по эксплуатации Telegram-бота для 3x-ui

## 1. Обзор

Этот бот помогает управлять **несколькими** панелями 3x-ui и следить за ними прямо из Telegram. Поддерживается многопользовательский и многопанельный режим, есть развитые функции администратора и автоматические задачи.

- **Администратор**: полный контроль — настройка бота, создание и удаление клиентов, управление панелями и пользователями, получение автоматических уведомлений.
- **Клиент (пользователь)**: получает от бота ссылку подписки, может запросить её повторно и посмотреть свой трафик.

### 1.1. Файлы и их назначение

| Файл | Назначение |
|------|-----------|
| `main.py` | Основной код бота: команды, диалоги, задачи по расписанию |
| `config.py` | Работа с `config.yml` (панели, пользователи, автоматизация) |
| `database.py` | Локальная база SQLite: трафик, привязки клиентов, пользователи бота |
| `xui_api.py` | HTTP-клиент панели 3x-ui |
| `query_logic.py` | Вспомогательная логика поиска трафика по email |
| `config.yml` | Ваш личный конфиг (токен, панели, админы) — **не коммитится** |
| `config.yml.example` | Шаблон конфига для новых установок |
| `MIGRATION.md` | Инструкция по переносу бота между серверами и SSL-настройке |
| `data/traffic.db` | Локальная база данных (переживёт пересборку контейнера) |
| `tests/` | Автотесты (запускаются командой `python3 -m pytest`) |

## 2. Требования к окружению

- **Python**: 3.9 или выше (рекомендуется 3.11)
- **Зависимости**: все пакеты из `requirements.txt`, установленные через `pip`

## 3. Подготовка

### 3.1. Получение токена Telegram-бота

1.  Найдите в Telegram `BotFather` и начните диалог.
2.  Отправьте команду `/newbot` и следуйте подсказкам.
3.  После создания BotFather выдаст **токен**. Скопируйте его и сохраните.

### 3.2. Получение вашего Telegram User ID

1.  Найдите в Telegram `userinfobot` и начните диалог.
2.  Бот сразу пришлёт ваши данные, включая `Id` — это ваш User ID.

## 4. Первичная настройка

### 4.1. Файл конфигурации

Создайте в корне проекта файл `config.yml` (скопировав `config.yml.example`) и заполните его:

```yaml
# 1. Токен Telegram-бота
bot_token: "YOUR_TELEGRAM_BOT_TOKEN"

# 2. Список авторизованных пользователей
users:
  admin_users:
    - 123456789  # Ваш Telegram User ID
  normal_users: []

# 3. Список панелей 3x-ui
panels:
  "TMT":
    url: "https://185.200.190.40:24487/x8UGpUW143YI9P3JVyQm"
    username: "your_username"
    password: "your_password"
    sub_url: "https://185.200.190.40:2096/sub"

# 4. Автоматические задачи
monthly_reset:
  enable: false

# 5. Настройки учёта трафика
traffic:
  accounting_mode: 'unidirectional'
```

**Важно:** URL панели должен включать **префикс** (например `/x8UGpUW143YI9P3JVyQm`), если он у вас настроен.

### 4.2. Установка и запуск

```bash
pip install -r requirements.txt
python3 main.py
```

Для фоновой работы — `nohup`, `tmux`, `screen` или Docker (см. раздел 8).

## 5. Команды бота

### 5.1. Команды администратора

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом |
| `/help` | Показать эту справку |
| `/setting` | Диалог добавления/обновления панели |
| `/inbounds <панель>` | Список инбаундов панели с их ID |
| `/addclient <tg_id> <email> <панель> <id1> [id2]...` | Создать клиента и выдать ему подписку |
| `/revoke <tg_id> [email]` | Удалить клиента из панели и БД |
| `/listclients` | Список всех выданных клиентов |
| `/status [панель]` | Статус сервера (без имени — по всем панелям) |
| `/listpanels` | Список настроенных панелей |
| `/delpanel <панель>` | Удалить панель |
| `/adduser <ID>` | Добавить обычного пользователя |
| `/deluser <ID>` | Удалить обычного пользователя |
| `/listusers` | Список авторизованных пользователей |
| `/setresetday <панель> <день>` | Установить день сброса трафика (1-28) |
| `/resetpanel <панель>` | Немедленно сбросить трафик панели |
| `/report` | Отправить дневной отчёт прямо сейчас |

### 5.2. Команды клиента

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом (регистрирует TG ID) |
| `/help` | Показать справку |

## 6. Типичный сценарий работы

### 6.1. Выдача подписки новому клиенту

1. **Клиент** открывает бота и нажимает `/start`. Бот запоминает его Telegram ID.
2. **Клиент** сообщает админу свой TG ID.
3. **Админ** создаёт клиента:
   ```
   /addclient 123456789 user123 TMT 8 9
   ```
   где `123456789` — TG ID клиента, `user123` — email, `TMT` — панель, `8 9` — ID инбаундов (vless + hysteria).
4. **Бот** спрашивает лимит HWID.
5. **Админ** вводит число (например `3`) или `/skip`.
6. **Бот**:
   - создаёт клиента в панели,
   - сохраняет связку в БД,
   - отправляет клиенту sub-ссылку,
   - отправляет админу подтверждение.

### 6.2. Повторная выдача ссылки клиенту

Клиент в любой момент может написать `/mylink` — бот пришлёт его ссылку.

### 6.3. Удаление клиента

```
/revoke 123456789
```
Удаляет все подписки указанного TG ID (или одну, если указан email).

## 7. Автоматические задачи

- **Оповещение о недоступности панели** (каждые 6 часов) — все админы получают алерт.
- **Напоминание об истечении инбаундов** (каждые 6 часов) — за 3 дня до окончания.
- **Ежедневный снимок трафика** (в 23:50 по Asia/Hong_Kong).
- **Дневной отчёт** (в 08:00) — отправляется всем админам, если включён.
- **Сброс трафика** (в 00:05) — по дню сброса каждой панели или по глобальной настройке.

## 9. FAQ

**В: Почему клиент не получает подписку?**
О: Проверьте, что он нажал `/start` у бота. Без этого бот не может написать ему первым.

**В: Как узнать ID инбаунда?**
О: Используйте `/inbounds TMT`. Бот покажет список с ID, remark, протоколом и портом.

**В: Клиент удалил чат с ботом — что делать?**
О: Подписка всё ещё работает (клиент подключается к Xray напрямую). Когда клиент снова запустит бота и напишет `/mylink` — получит ссылку.

**В: Можно ли создать одного клиента в нескольких панелях?**
О: Один `client_binding` привязан к одной панели. Если нужен клиент в двух панелях — используйте `/addclient` дважды с разными панелями. При этом TG ID может быть один и тот же.
