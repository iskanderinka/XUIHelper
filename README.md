## ✨ Основные возможности

- **Мультипанельность**: один бот — все ваши панели 3x-ui.
- **Мониторинг статуса**: состояние сервера, трафика и ядра Xray в любой момент.
- **Несколько каналов запроса**: самопроверка через **Telegram-бота** и через **веб-браузер**.
- **Автоматические задачи**:
    - Оповещение о недоступности панелей.
    - Напоминание об истечении инбаундов.
    - Ежемесячный автосброс трафика всех пользователей.
- **Безопасность**: ролевое разграничение прав администратора и обычных пользователей.

## 🚀 Быстрый старт (Docker — рекомендуемый вариант)

Самый простой и надёжный способ развёртывания: три шага — и бот работает.

### Шаг 1. Подготовка окружения

Убедитесь, что на сервере установлены [Docker](https://docs.docker.com/engine/install/) и [Docker Compose](https://docs.docker.com/compose/install/).

### Шаг 2. Скачивание и настройка проекта

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/GeQainZz/TgXUIMgr.git
    cd TgXUIMgr
    ```

2.  **Создайте и отредактируйте файл конфигурации:**
    Скопируйте шаблон:
    ```bash
    cp config.yml.example config.yml
    ```
    Затем откройте `config.yml` в `vim` или любом другом редакторе и заполните данные.

    **Разбор файла `config.yml`:**
    ```yaml
    # 1. Токен Telegram-бота (обязательно)
    # Получите у @BotFather в Telegram
    bot_token: "YOUR_TELEGRAM_BOT_TOKEN"

    # 2. Авторизованные пользователи (обязательно)
    users:
      # Список ID администраторов. Первый считается супер-администратором
      admin_users:
        - 123456789  # Замените на ваш Telegram User ID

      # Список ID обычных пользователей (опционально)
      normal_users:
        - 987654321

    # 3. Список ваших панелей 3x-ui (опционально, можно добавить позже через бота)
    # "Произвольное имя панели": { ... }
    panels:
      "Мой сингапурский узел":
        url: "http://your-panel-url.com:port"
        username: "your_username"
        password: "your_password"
      "Резервный сервер":
        url: "http://another-panel.com:port"
        username: "admin"
        password: "password123"
    ```
    > **Как узнать Telegram User ID?**
    > Найдите в Telegram `@userinfobot` и начните диалог — он сразу пришлёт ваш User ID.

### Шаг 3. Запуск бота!

В корне проекта выполните:

```bash
docker-compose up -d --build
```

Готово! Бот и веб-сервис работают в фоне.

## 📖 Руководство по использованию

После запуска сервиса есть два способа взаимодействия.

### Способ 1. Веб-страница (рекомендуется)

Самый удобный способ — не нужно ставить никаких приложений.

1.  Откройте в браузере `http://<IP-вашего-сервера>:5000`.
2.  Введите «Имя панели» и «Ваш логин (email)».
3.  Нажмите «Проверить» — увидите актуальные данные о трафике.

### Способ 2. Запрос через Telegram-бота

Для тех, кто пользуется Telegram.

#### Команды администратора

| Команда | Параметры | Описание |
| :--- | :--- | :--- |
| `/setting` | нет | Диалоговое добавление или обновление панели. |
| `/listpanels`| нет | Список всех панелей, прописанных в `config.yml`. |
| `/delpanel` | `<имя панели>` | Удалить панель из конфигурации. |
| `/status` | `[имя панели]` | Статус панели. С именем — подробный статус сервера; без имени — краткая сводка. |
| `/adduser` | `<ID>` | Добавить обычного пользователя. |
| `/deluser` | `<ID>` | Убрать обычного пользователя. |
| `/listusers` | нет | Список администраторов и обычных пользователей. |
| `/help` | нет | Справка. |

#### Команды обычного пользователя

| Команда | Параметры | Описание |
| :--- | :--- | :--- |
| `/query` | `<панель> <имя>` | Информация о ноде: расход и срок действия. |
| `/help` | нет | Справка. |

## 🔧 Управление Docker

Полезные команды для управления ботом.

-   **Просмотр логов в реальном времени**:
    ```bash
    docker-compose logs -f
    ```

-   **Остановка и удаление контейнера**:
    ```bash
    docker-compose down
    ```

-   **Пересборка после обновления кода**:
    1.  Остановить контейнер: `docker-compose down`
    2.  Забрать свежий код: `git pull`
    3.  Пересобрать и запустить: `docker-compose up -d --build`

## ⚙️ Ручное развёртывание (для опытных)

Если не хотите использовать Docker, можно развернуть вручную.

1.  **Установите зависимости**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **Настройте `config.yml`**:
    См. раздел про Docker выше — создайте файл с теми же полями.
3.  **Запустите бота**:
    Для долгой работы используйте `nohup` или `tmux`/`screen`:
    ```bash
    nohup python main.py &
    ```

## ⁉️ FAQ

**В: Как узнать свой Telegram User ID?**
О: Найдите в Telegram `@userinfobot` и начните диалог — он сразу пришлёт ваш User ID.

**В: Почему обычный пользователь не может выполнить `/query myuser`?**
О: Бот поддерживает несколько панелей, поэтому при запросе нужно указывать панель. Формат: `/query <панель> <имя>`. Пример: `/query Мой сингапурский узел myuser`.

**В: Бот сообщает «Слишком частые запросы. Временная блокировка». Что это?**
О: Защита от злоупотреблений. Если за 5 минут **5 раз** запросить несуществующего пользователя, доступ временно блокируется (по умолчанию на 2 часа). Проверьте имя панели и email и подождите.

**В: Как работает защита от частых запросов на веб-странице?**
О: По **IP-адресу** посетителя. Если один и тот же IP за 5 минут ошибётся 5 раз, IP блокируется на 2 часа — защита от вредоносных запросов к API.
